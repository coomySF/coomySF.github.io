# Beat Sheet — 領導者的四種 Loop・發表會版本

- Preset: `knowledge`
- 觀眾: 帶團隊的主管；看完要能複述「四種 Loop 各是什麼、它們不是階梯、領導者要設計的是切換條件」。
- 視覺語域: `keynote`（深藍黑漸層 `#0a0f1e → #141b33`、毛玻璃卡片（半透明白 6–10% + 1px 高光邊 + backdrop blur）、柔光暈只落在當前焦點、微視差；動效只有位移 + 淡入 + 縮放 0.96→1；四種 Loop 各一個高亮但不螢光的色）
- 素材根目錄: `in-svg`
- 判定依據: 使用者未提供截圖 / 錄影；證據畫面全部為自繪 SVG 線稿（依 preset 規則 5），`證據畫面` 欄填 SVG 場景 id。
- 來源: `_posts/2026-08-05-leadership-agent-loops.md`（原文約 3,000 字 → 9 個論點 beat + 1 recap）
- Shell: film layout + sticky stage；動畫以 SVG.js Runner / Timeline 依 scroll 進度 seek（`cinematic-svg-animation` + `svgjs`），不用 Three.js。
- 版本: keynote（第三種風格，2026-08-27；同 10 beat、同論點）

## B1 — 主管一直在選 Loop
- 論點: 領導者管專案時，其實一直在替每個人選 Loop，只是沒這樣說。
- 證據畫面: `svg:leader-picks-loops`
- 畫面說明: 中央一個主管節點（圓 + 短線構成的極簡人形），四條線稿環從節點依序描線畫出，環上各標一個小字：回合 / 目標 / 時間 / 主動。
- 鏡頭: zoom-in（「看這裡」：viewBox 從全景收到主管節點再放開，澄清「是主管在選」）
- 停留: 1.3

## B2 — 要主動卻只給回合
- 論點: 嘴上要 ownership，實際只允許 Turn-Based，最後又怪人不主動。
- 證據畫面: `svg:locked-in-turn-loop`
- 畫面說明: 左側一個人形被一個小環描線圈住；右側一個大而虛線的「主動」環微微呼吸；中間一道實線牆。
- 鏡頭: static（論點是狀態對比，畫面靜止即可）
- 停留: 1.3

## B3 — 一步一請示
- 論點: Turn-Based 適合第一次、不可逆、事故中；永不結束時，等待最合理。
- 證據畫面: `svg:turn-based-pingpong`
- 畫面說明: 主管與團員兩個節點之間一顆小圓來回四次，每回合底下時間軸長出一格刻度；最後小圓停在主管側，團員側的線條變淡。
- 鏡頭: pan（順序：跟著光球來回，澄清「每一步都要回去」）
- 停留: 1.6

## B4 — 給結果不只給責任
- 論點: Goal-Based 要給齊五條件：結果、自決範圍、資源、求援訊號、回看時機。
- 證據畫面: `svg:goal-with-five-tokens`
- 畫面說明: 右上一面旗（目標）；團員節點沿一條手繪感曲線走向旗子；路徑旁五個小方框依序描線並填入五個詞。
- 鏡頭: pan（順序：五顆方塊依序亮，澄清「五個條件」）
- 停留: 1.6

## B5 — 節奏是為了早看見
- 論點: Time-Based 重點不是幾天開一次會，而是有沒有更早看見問題並改下一步。
- 證據畫面: `svg:checkpoints-catch-risk`
- 畫面說明: 一條水平時間軸、五個等距檢查點刻度；一條銅色風險曲線慢慢上揚，每碰到檢查點就被壓回，最後不超過警戒虛線。
- 鏡頭: pan（順序：沿時間軸前進，澄清「在檢查點被提早看見」）
- 停留: 1.4

## B6 — 知道哪裡不必等
- 論點: Proactive 需要資訊與邊界；沒有的話會變成不敢動或衝過頭兩種極端。
- 證據畫面: `svg:boundary-and-beacon`
- 畫面說明: 一個虛線方形邊界內，團員節點自由畫出軌跡；碰邊時角落一顆信號燈亮起。之後邊界淡出：一個節點縮成點不動、另一個直線衝出畫面。
- 鏡頭: cross-fade（同一主體改變狀態：有邊界 → 無邊界）
- 停留: 1.6

## B7 — 同一人不同 Loop
- 論點: 四種 Loop 不是階梯；同一人熟事可主動，遇事故切回回合制。
- 證據畫面: `svg:same-person-two-loops`
- 畫面說明: 同一個團員節點；左半場繞一個大環自由走，右半場（銅色警示標記）被小環圈住、與主管節點來回連線。
- 鏡頭: cross-fade（同一主體改變狀態：日常 → 事故）
- 停留: 1.4

## B8 — 設計切換條件
- 論點: 領導者最重要的工作不是把人推向 Proactive，而是知道什麼時候切換。
- 證據畫面: `svg:switch-dial`
- 畫面說明: 一個四段式刻度盤（回合 / 目標 / 時間 / 主動）；四張條件卡依序描線出現，指針依序轉到對應段位。
- 鏡頭: pan（順序：四張卡依序翻，澄清「條件 → 對應 Loop」）
- 停留: 1.8

## B9 — 先看 Loop 再看人
- 論點: 「他不夠主動」先不當人格判斷；先看我們讓他用哪種 Loop、有沒有離開的條件。
- 證據畫面: `svg:ring-opens`
- 畫面說明: B2 的小環半徑慢慢放大，團員節點走出環外；中間那道牆縮成一點消失。
- 鏡頭: zoom-in（「看這裡」：viewBox 收到張開的環，澄清「條件給了人就能離開」）
- 停留: 1.4

## B10 — 回顧
- 論點: 主管一直在選 Loop／要主動卻只給回合／一步一請示／給結果不只給責任／節奏是為了早看見／知道哪裡不必等／同一人不同 Loop／設計切換條件／先看 Loop 再看人
- 證據畫面: `svg:four-rings-recap`
- 畫面說明: 四個線稿環並排靜止（各自的色與名稱），九個 headline 依序在下方排成一列。
- 鏡頭: static（回顧，畫面靜止）
- 停留: 2.0
