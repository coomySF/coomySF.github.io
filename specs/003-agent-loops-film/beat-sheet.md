# Beat Sheet — 領導者的四種 Loop・動畫版本

- Preset: `knowledge`
- 觀眾: 帶團隊的主管；看完要能複述「四種 Loop 各是什麼、它們不是階梯、領導者要設計的是切換條件」。
- 素材根目錄: `in-canvas`
- 判定依據: 使用者未提供截圖 / 錄影，只有原文與一張引用的 GIF（不可直接重製）；證據畫面全部由 Three.js 場景自行產出（依 preset 規則 5），`證據畫面` 欄填場景 id。
- 來源: `_posts/2026-08-05-leadership-agent-loops.md`（原文約 3,000 字 → 9 個論點 beat + 1 recap）
- Shell: 沿用 `_posts/2026-08-12-life-pastel.html` 的 film layout + sticky stage + scroll→keyframe 機制；粉彩畫風，與原文的 noir 開場區隔。

## B1 — 主管一直在選 Loop
- 論點: 領導者管專案時，其實一直在替每個人選 Loop，只是沒這樣說。
- 證據畫面: `scene:leader-picks-loops`
- 畫面說明: 一個主管角色站中央，四條不同顏色的環（回合 / 目標 / 時間 / 主動）從他手上延伸到四個團員腳下。
- 鏡頭: zoom-in（「看這裡」：視線從主管拉到四條環，澄清「是主管在選」）
- 停留: 1.3

## B2 — 要主動卻只給回合
- 論點: 嘴上要 ownership，實際只允許 Turn-Based，最後又怪人不主動。
- 證據畫面: `scene:locked-in-turn-loop`
- 畫面說明: 團員被一個很小的環圈住，遠處一個大而透明的「主動」環在發光，中間是牆。
- 鏡頭: static（論點是狀態對比，畫面靜止即可）
- 停留: 1.3

## B3 — 一步一請示
- 論點: Turn-Based 適合第一次、不可逆、事故中；永不結束時，等待最合理。
- 證據畫面: `scene:turn-based-pingpong`
- 畫面說明: 主管與團員之間一顆光球來回；每來回一次路上長出一格；後段團員停下不動、格子不再長。
- 鏡頭: pan（順序：跟著光球來回，澄清「每一步都要回去」）
- 停留: 1.6

## B4 — 給結果不只給責任
- 論點: Goal-Based 要給齊五條件：結果、自決範圍、資源、求援訊號、回看時機。
- 證據畫面: `scene:goal-with-five-tokens`
- 畫面說明: 遠方山丘上一面旗；團員自己畫路走過去；身邊繞著五顆標示條件的小方塊逐一亮起。
- 鏡頭: pan（順序：五顆方塊依序亮，澄清「五個條件」）
- 停留: 1.6

## B5 — 節奏是為了早看見
- 論點: Time-Based 重點不是幾天開一次會，而是有沒有更早看見問題並改下一步。
- 證據畫面: `scene:checkpoints-catch-risk`
- 畫面說明: 一條時間軸上等距立著檢查點；一根風險柱慢慢長高，在檢查點被壓回去，而不是等到最後才爆。
- 鏡頭: pan（順序：沿時間軸前進，澄清「在檢查點被提早看見」）
- 停留: 1.4

## B6 — 知道哪裡不必等
- 論點: Proactive 需要資訊與邊界；沒有的話會變成不敢動或衝過頭兩種極端。
- 證據畫面: `scene:boundary-and-beacon`
- 畫面說明: 團員在一個發光的方形邊界內自由移動；碰到邊界時一座信號燈亮起、主管出現；邊界消失時團員一半縮成一團、一半衝出畫面。
- 鏡頭: cross-fade（同一主體改變狀態：有邊界 → 無邊界）
- 停留: 1.6

## B7 — 同一人不同 Loop
- 論點: 四種 Loop 不是階梯；同一人熟事可主動，遇事故切回回合制。
- 證據畫面: `scene:same-person-two-loops`
- 畫面說明: 同一個團員角色，左半場繞大環自由走，右半場（警報紅光）站在小環裡與主管一步一步對。
- 鏡頭: cross-fade（同一主體改變狀態：日常 → 事故）
- 停留: 1.4

## B8 — 設計切換條件
- 論點: 領導者最重要的工作不是把人推向 Proactive，而是知道什麼時候切換。
- 證據畫面: `scene:switch-dial`
- 畫面說明: 一個四段式旋鈕（回合 / 目標 / 時間 / 主動），四張條件卡依序翻面，指針跟著卡片轉到對應段位。
- 鏡頭: pan（順序：四張卡依序翻，澄清「條件 → 對應 Loop」）
- 停留: 1.8

## B9 — 先看 Loop 再看人
- 論點: 「他不夠主動」先不當人格判斷；先看我們讓他用哪種 Loop、有沒有離開的條件。
- 證據畫面: `scene:ring-opens`
- 畫面說明: B2 那個小環慢慢張開變大，團員從裡面走出來；主管把牆放下。
- 鏡頭: zoom-in（「看這裡」：視線落在張開的環，澄清「條件給了人就能離開」）
- 停留: 1.4

## B10 — 回顧
- 論點: 主管一直在選 Loop／要主動卻只給回合／一步一請示／給結果不只給責任／節奏是為了早看見／知道哪裡不必等／同一人不同 Loop／設計切換條件／先看 Loop 再看人
- 證據畫面: `scene:four-rings-recap`
- 畫面說明: 四色環並排靜止，九個 headline 依序在畫面下方排成一列。
- 鏡頭: static（回顧，畫面靜止）
- 停留: 2.0
