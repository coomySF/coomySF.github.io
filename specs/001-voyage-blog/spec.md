# Feature Specification: 星際航行部落格（The Voyage Blog）

**Feature Branch**: `001-voyage-blog`
**Created**: 2026-08-06
**Status**: Implemented
**Input**: User description: "個人長文部落格：首頁以捲動敘事電影呈現（飛船巡迴 RD/PM/QA/AI 星球接人、終幕凝聚為 SpecFormula），下接最新文章卡片與 About；支援合成音效、文章上下架、深色書庫。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 閱讀文章 (Priority: P1)

訪客從首頁卡片或書庫進入單篇文章，以米紙色版面舒適閱讀長文，文末可接續閱讀下一篇。

**Why this priority**: 部落格的核心價值是長文本身；所有動畫與敘事都是通往閱讀的路，閱讀不成立則整站不成立。

**Independent Test**: 直接開啟任一文章網址即可完整驗證——不需要首頁動畫存在。

**Acceptance Scenarios**:

1. **Given** 站內有已發布文章, **When** 訪客點擊首頁卡片, **Then** 顯示該篇文章內頁（標題、日期、預估閱讀分鐘數、全文）
2. **Given** 訪客閱讀至文末, **When** 檢視繼續閱讀導覽, **Then** 顯示下一篇（或無下一篇時上一篇）的卡片連結
3. **Given** 相鄰文章被標記隱藏, **When** 檢視繼續閱讀導覽, **Then** 導覽略過隱藏文章

---

### User Story 2 - 首頁航行旅程 (Priority: P2)

訪客捲動首頁，線框飛船依序飛過 RD、PM、QA、AI 四顆各具顏色的星球，於每站接走一位有辨識度的乘客（藍色戴眼鏡工程師、綠色打領帶產品經理、金色持放大鏡測試員、橘紅色小怪物），終幕飛船變彩並顯示 SpecFormula 字樣與群舞。

**Why this priority**: 首頁是品牌敘事的載體——「把分散的職能聚在一起」正是 SpecFormula 的故事，用旅程講一次。

**Independent Test**: 於支援 3D 繪圖的瀏覽器捲動首頁一輪，逐站核對站名、乘客與終幕字樣。

**Acceptance Scenarios**:

1. **Given** 首頁載入完成, **When** 訪客尚未捲動, **Then** 標題畫面靜止且顯示開始按鈕
2. **Given** 訪客捲動至各站區間, **When** 星球停靠, **Then** 星球中央顯示站名且乘客自星球飛入飛船
3. **Given** 訪客捲動至終幕, **When** 全員到齊, **Then** 飛船彩色閃爍、顯示 SpecFormula 字樣、四位乘客於前方跳舞
4. **Given** 瀏覽器不支援 3D 繪圖或使用者偏好減少動態, **When** 瀏覽首頁, **Then** 以靜態文字版面呈現標題與文章卡片

---

### User Story 3 - START 引導與聲音 (Priority: P3)

訪客點擊開始按鈕後，鏡頭平滑滑入旅程、聲音（未靜音者）淡入，隨後出現繼續捲動提示；聲音開關永遠反映實際發聲狀態。

**Why this priority**: 解決兩個進入門檻——「不知道要捲動」與「瀏覽器手勢後才能發聲」，把它們合併成一次點擊。

**Independent Test**: 全新無偏好狀態載入首頁，僅操作開始按鈕與聲音開關即可驗證全部狀態轉移。

**Acceptance Scenarios**:

1. **Given** 頁面載入且尚無互動, **When** 檢視聲音開關, **Then** 顯示為關（尚未實際發聲）
2. **Given** 訪客未曾靜音, **When** 點擊開始按鈕, **Then** 畫面於 2.4 秒內滑至飛船登場幕、聲音淡入、開關轉為開
3. **Given** 開始滑行啟動 1.1 秒後, **When** 滑行接近停止, **Then** 顯示繼續捲動提示；訪客續捲後提示淡出
4. **Given** 訪客曾手動靜音, **When** 點擊開始按鈕, **Then** 僅滑動鏡頭，聲音維持關閉

---

### User Story 4 - 文章上下架 (Priority: P4)

作者在文章加上隱藏標記即可下架：自首頁卡片、書庫列表與繼續閱讀導覽消失，但既有網址仍可直接開啟；移除標記即重新上架。

**Why this priority**: 內容營運需要「先收起來但不斷鏈」的中間態；無此功能只能刪文或硬扛。

**Independent Test**: 對任一文章切換隱藏標記並重建站點，核對三處列表與直連網址。

**Acceptance Scenarios**:

1. **Given** 文章被標記隱藏, **When** 訪客瀏覽首頁與書庫, **Then** 該篇不出現且書庫篇數改計可見篇數
2. **Given** 文章被標記隱藏, **When** 知道網址的訪客直接開啟, **Then** 文章仍完整可讀
3. **Given** 隱藏標記被移除, **When** 站點重建, **Then** 文章恢復出現於所有列表

---

### User Story 5 - 書庫瀏覽 (Priority: P5)

訪客在深色書庫頁瀏覽全部可見文章：大字排版列表、每篇附編號、日期、分類、預估閱讀分鐘數；hero 右側一顆懸浮結晶球，游標移入會綻開。

**Why this priority**: 文章量成長後首頁四卡不足以承載全覽需求；書庫是長期的目錄頁。

**Independent Test**: 開啟 /writing/ 即可獨立驗證列表完整性與結晶球互動。

**Acceptance Scenarios**:

1. **Given** 站內有可見文章, **When** 訪客開啟書庫, **Then** 依日期新至舊列出全部可見文章與總篇數
2. **Given** 訪客游標移入結晶球, **When** 停留, **Then** 結晶球粒子向外綻開並增亮；移出即收合

---

### Edge Cases

- 瀏覽器不支援 3D 繪圖 → 靜態降級版面，內容照常可讀（US2-4）
- 使用者偏好減少動態（reduced motion）→ 同靜態降級
- 背景分頁 → 動畫由瀏覽器暫停屬預期行為，回前景自動恢復
- 曾靜音者點開始按鈕 → 不得發聲（尊重偏好優先於預設開聲）
- 快速來回捲動 → 場景為捲動進度之純函式，任意位置可完整還原，不得殘留中間態
- 隱藏文章曾被分享的外部連結 → 直連仍可讀，不產生 404
- 行動裝置 → 卡片改單欄、粒子數降載、像素密度上限 1.5

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 首頁標題畫面 MUST 於使用者互動前保持靜止，並顯示可點擊的開始按鈕
- **FR-002**: 系統 MUST 於訪客點擊開始按鈕後 2.4 秒內平滑滑動至飛船登場幕
- **FR-003**: 系統 MUST 於開始滑行啟動 1.1 秒後顯示繼續捲動提示，並於訪客續捲後淡出
- **FR-004**: 旅程 MUST 依捲動進度依序呈現：飛船登場閃光 → RD → PM → QA → AI 四站接人 → 終幕
- **FR-005**: 每站星球 MUST 以該站乘客的專屬顏色呈現，站名顯示於星球中央
- **FR-006**: 每位乘客 MUST 具備可辨識的造型（眼鏡／領帶／放大鏡／怪物），登船瞬間飛船 MUST 閃光一次
- **FR-007**: 終幕 MUST 顯示 SpecFormula 字樣、飛船彩色閃爍與四位乘客群舞，結束後飛船 MUST 離場不遮擋後續內容
- **FR-008**: 聲音 MUST 全程式合成（零音檔），且在瀏覽器手勢發生前不得實際發聲
- **FR-009**: 聲音開關 MUST 顯示實際發聲狀態；手動靜音偏好 MUST 被記住並優先於預設開聲
- **FR-010**: 首頁 MUST 顯示最新至多 4 篇可見文章的純排版卡片（編號浮水印、日期、分類、標題、摘要）
- **FR-011**: 文章加上隱藏標記後 MUST 自首頁卡片、書庫列表、繼續閱讀導覽排除；其網址 MUST 仍可直接開啟
- **FR-012**: 書庫 MUST 列出全部可見文章並顯示可見篇數；每列含編號、日期、分類、預估閱讀分鐘數
- **FR-013**: 不支援 3D 繪圖或偏好減少動態時，系統 MUST 以靜態版面完整呈現標題、文章與 About
- **FR-014**: 首頁所有文案 MUST 存在於真實 DOM（不依賴 canvas 呈現文字），供搜尋引擎與輔助工具讀取
- **FR-015**: About 區塊 MUST 位於首頁底部，含大頭照與 Threads 連結；導覽的關於 MUST 錨定至此

### Key Entities

- **文章（Post）**: 標題、日期、分類、摘要、內文、隱藏標記（布林；預設不隱藏）
- **旅程站點（Station）**: 站名（RD／PM／QA／AI）、專屬顏色、出場區間、乘客
- **乘客（Crew）**: 造型特徵、身體顏色、所屬站點；終幕群舞成員
- **聲音偏好（Sound Preference）**: 實際發聲狀態、使用者靜音偏好（跨造訪記憶）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 訪客不點擊任何按鈕、僅捲動，即可於 60 秒內完整看完旅程並抵達文章卡片
- **SC-002**: 全新訪客載入至互動可用（標題可讀、開始按鈕可點）不超過 3 秒（一般寬頻）
- **SC-003**: 首頁在互動前的聲音輸出為零；點擊開始按鈕後 2 秒內環境聲淡入完成
- **SC-004**: 標記隱藏後重建站點，該文章於首頁、書庫、繼續閱讀三處出現次數皆為 0；直連網址回應完整內文
- **SC-005**: 停用 JavaScript 時，首頁仍可讀取標題、副標與全部可見文章連結
- **SC-006**: 桌機動畫維持 60fps；行動裝置降載後不低於 30fps
