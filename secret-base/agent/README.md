# 秘密基地的腦（跑在家裡的 Mac）

孩子對娃娃說話 → 後端轉文字 → **這支程式**每 15 秒來拿還沒回的話 → `claude -p`（吃個人訂閱）判斷
→ 娃娃要不要先回、回什麼；給爸媽的小抄（狀態、建議、陪伴提議、三句一鍵回）→ 送回後端
→ 後端用娃娃的聲音念成信給孩子、小抄發到 Discord、回信頁的快速回覆換成那三句。

## 規則

| 孩子說的 | mode | 娃娃 |
|---|---|---|
| 日常分享、抒發、問娃娃 | doll | 「我忙」時先回；「我在」時不回，留給爸媽 |
| 找爸媽、要大人決定的事 | pass | 只說會把話帶到 |
| 受傷、怕某人、保密、不想活 | urgent | 固定一句「我會請媽媽來」；Discord 🚨 @here |
| 聽不懂 | skip | 不回 |

「我在／我忙」在回信頁右上角切換。小抄每一則都產，跟娃娃有沒有回無關。

## 安裝

1. `~/.config/secret-base/agent.env` 放 `SECRET_BASE_AGENT_KEY=…`（與 Supabase secret 同一把）
2. `./install.sh`：裝成 launchd 使用者服務，登入即跑、掛掉自動重啟
3. 日誌在 `agent.log`（只記程式運作，對話內容都在資料庫）

Mac 睡著或額度用完時娃娃不會先回，但 Discord 的原始通知照常，等於退回家長親口回。
`claude` 連續失敗兩次的那一則會標成 skip，不會一直重試燒額度。

`.gitignore` 忽略這裡的 `*.log`。
